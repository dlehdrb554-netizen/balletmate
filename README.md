# Balletmate 🩰

Mobile-first ballet studio discovery app built with Expo / React Native.

## Prototype features
- Interactive map and sample studio markers
- Search by studio name, district, or class tag
- Quick filters: adults, kids, coupon, beginner
- Filter sheet: adult/kids, level, coupon
- Moved-map area search prompt
- Request current location and center map
- Map/list view switch and selected studio preview

> Studio names, locations, ratings, and prices are illustrative mock data and have not been verified.

## Local setup
- Node.js LTS
- `npm install`
- `npx expo start`
- Scan with Expo Go (matching SDK) or run a simulator

## Roadmap
- Real map-area filtering and responsive map/list UX
- Studio details, class schedule, duration, pricing and contact
- Favorites and compare
- Source real studio information responsibly; review provider/API terms before ingestion
- Backend, caching, and server-side usage limits for free-tier protection

Do not commit API keys, access tokens, or private credentials.
